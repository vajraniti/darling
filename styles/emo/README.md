# эмо — тёмное эмо

Вторая земля борда — чёрная. Свет остаётся только на волосах и коже.

## Рефы (картинки не сохранились — описание)

- **реф 6** — лицо под рваной чёлкой, белые пряди на чистом чёрном, жёсткий контраст, в углу мелкое «…COMPUTER».
- **реф 9** — вебка в пикселях: только губы и шея, бледная кожа, ржавые пятна на шее.
- **реф 10** — сердце в языках пламени, Y2K-трайбл, сложенный зеркалом как калейдоскоп; шум, лиловый отлив, пересвеченные края.

## Названия

- **MySpace angle / fringe emo** (реф 6) — съёмка себя сверху вниз с чёлкой на глаза. Juliet Simms (Automatic Loveletter): селфи придумали эмо-кидс. Сцена распалась в 2009–2011 с уходом с MySpace на Facebook.
- **Analog horror** (реф 9) — жанр испорченной записи: Local 58 Криса Страуба (26.10.2015), Gemini Home Entertainment (2019), The Mandela Catalogue (2021).
- **Webcore / Internetcore** — ностальгия по вебу 90-х и нулевых, замечена около 2020.
- **Corecore** — нарезки под грустную музыку; Tumblr с 2020, TikTok в 2022.
- **Y2K-трайбл** (реф 10) — языки пламени и сердца через Ed Hardy и Affliction; ревайвл в 2021, Screenshot (2022) назвал тренд «ChromeHeartscore» / «Affliction McBling».
- **Cybersigilism / neo-tribal** — наследник трайбла. По 032c, перешёл из мерча Drain Gang, Sad Boys и Haunted Mound в дизайн Карти и Кена Карсона. Тату-мастера по подборке Dazed (май 2025): @ryuritneyspears, @swagatattoo, @byuki_ttt.
- **Зеркало / калейдоскоп** — отдельного названия нет, приём из glitch- и Y2K-инструментов.
- **Граница** — ржавые пятна на шее: край guro и ero guro.
- **Scene / MySpace emo**, **emo rap / GothBoiClique** (LA, 2012; Lil Peep с 2016) — шире по теме.
