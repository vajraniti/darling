# Пример: HTTP в опиуме

Задание: сайт про HTTP в стиле Opium — коды ответа как трек-лист альбома: зин-обложка спереди и оборот с трек-листом. Живое: выбрать «трек» и получить его настоящий смысл и класс.

Живая версия: https://claude.ai/artifact/XGjgipe83iKiSVmuo3UYiJ. Файл `index.html` открывается локально без сборки; ссылки вида `#418` открывают нужный трек.

## Ход

Метафора взята из устройства самих кодов, а не наклеена сверху:

- **Первая цифра — сторона, две последние — номер трека.** RFC 9110: «The first digit of the status code defines the class of response. The last two digits do not have any categorization role». Значит, 404 — сторона 4, трек 04, как A1, A2 на конверте.
- **Оборот — крест.** Как на обороте винила MUSIC (2025): столбец по центру, стороны 1XX–5XX, номера заново на каждой стороне, плечи креста — IETF и HTTP.
- **Скрытые треки.** 306 и 418 в RFC 9110 значатся как «(Unused)». У 418 своя история: шутка из первоапрельского RFC 2324, которую так часто ставили, что код пришлось зарезервировать. На вкладыше 418 — серебряный чайник Пола Ревира (около 1782): серебро без логотипа, в духе Chrome Hearts.
- **Лицевая — номер зина.** Схема Slash №1 (1977) и Whole Lotta Red (2020): белая бумага, чёрный блок, красный знак поверх края, строка выпуска «STD 97 · RFC 9110 · июнь 2022 · IETF» и вертикальная «http semantics» — это настоящий номер стандарта, дата, издатель и название документа.
- **Любой код.** Поле «Любой код» принимает и то, чего нет в трек-листе: по RFC 9110 клиент обязан понять класс неизвестного кода и прочитать его как x00 (471 → 400), а коды вне 100–599 недействительны и читаются как 5xx.

## Факты

- Все 46 кодов, английские фразы и цитаты взяты из текста RFC 9110 (раздел 15) скриптом сборки, без перепечатки руками. Русский смысл пересказан по первому абзацу каждого подраздела. Полная таблица и дословный текст про 418 — в `SOURCES.md`.
- Эвристически кэшируемые коды (200, 203, 204, 206, 300, 301, 308, 404, 405, 410, 414, 501) — из RFC 9110, § 15.1.
- «418 I'm a teapot» и «тело ответа МОЖЕТ быть низеньким и пузатым» — RFC 2324, § 2.3.2.
- Проверка: локально через http://localhost на ширине 1440 и 390 — горизонтального скролла нет, ошибок в консоли нет, шрифт загружен, клик по 418 и ввод 471 работают.
