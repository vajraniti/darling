http semantics

STD 97 · RFC 9110июнь 2022IETF

HTTP — протокол, на котором держится веб. На каждый запрос сервер отвечает трёхзначным кодом. RFC 9110 определяет сорок шесть таких кодов: первая цифра задаёт класс ответа, а две последние, как сказано в стандарте, классификации не несут. Здесь это пластинка. Первая цифра — сторона, две последние — номер трека.

Фразы вроде Not Found стандарт называет только рекомендацией: их можно заменить своими или опустить, протоколу всё равно. Поэтому рядом с каждой стоит перевод.

На обложке плакальщик с надгробия Филиппа Смелого, герцога Бургундского. Клаус де Верве, 1404–1410, алебастр. Кливлендский музей искусств.

Исходный сервер не нашёл текущего представления ресурса или не хочет признавать, что оно есть. Временно это или навсегда, код не говорит.

The 404 (Not Found) status code indicates that the origin server did not find a current representation for the target resource or is not willing to disclose that one exists.
