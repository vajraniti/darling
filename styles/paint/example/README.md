# Пример: электронная подпись красками

Задание Гэгэ: пример в стиле «девушки красками» на тему электронной цифровой подписи, на его рефах, размером как BLAKE3.

Живая версия: https://claude.ai/artifact/MvauRUiNvWgCmDF6oLYiCR. Файл `index.html` работает локально, но подпись требует безопасного контекста: открывай через https или `http://localhost` (например `python3 -m http.server`), не как `file://`.

## Ход

- **Подпись = клятва невесты под вуалью.** Герой — реф 7: вуаль, жемчуг, снег. Рядом письмо, его подписывают настоящим ключом Ed25519 прямо в браузере (Web Crypto API).
- **Целостность видна руками.** Любая правка письма — и подпись перестаёт сходиться; кнопка «подписать заново» ставит новую.
- **Два ключа = две девушки.** Закрытый ключ прячется в темноте — реф 8, призрак на чёрном; открытый виден всем и показан на странице.
- **Три обещания** — целостность, подлинность, неотказуемость — из стандарта NIST FIPS 186-5; рядом деталь рефа 7, чокер под вуалью.
- **Письмо** — сонет Кристины Россетти «Remember»: прерафаэлиты — родня этой живописи.

## Факты

- FIPS 186-5 (NIST, 3 февраля 2023): подпись выявляет изменения данных, подтверждает подписавшего и даёт неотказуемость — «the signatory cannot easily repudiate the signature».
- RFC 8032: у Ed25519 ключи по 32 байта, подпись 64 байта; подписи EdDSA детерминированы.
- MDN, SubtleCrypto.sign: Ed25519 и ECDSA поддерживаются, нужен безопасный контекст; подпись ECDSA — формат IEEE P1363. Если браузер не умеет Ed25519, страница берёт ECDSA P-256.
