# Пример: TCP — три аккорда

Задание: сайт про трёхстороннее рукопожатие TCP — SYN, SYN-ACK, ACK — как панк-зин. Кивок — рисунок из зина Sideburns 1977 года: «This is a chord, this is another, this is a third. Now form a band» превращается в «а теперь установи соединение».

Живая версия: https://claude.ai/artifact/7BYuNDi2dza668AALyixYP. Файл `index.html` самодостаточный (SHA-256 написан на JS, сеть нужна только шрифтам), открывается локально.

## Ход

Метафора взята из устройства протокола, а не наклеена сверху:

- **Флаги = струны.** В RFC 9293 имена восьми флагов стоят столбиками, буква под буквой — как струны на аккордовой сетке. Аккорд — какие струны зажаты: SYN, SYN + ACK, ACK. Первый экран — страница Sideburns заново: три сетки лесенкой, «← вот аккорд / вот ещё один / вот третий», внизу подчёркнуто «а теперь установи соединение».
- **Номера настоящие.** Начальный номер считается по формуле из RFC: ISN = M + F, где M — счётчик с шагом 4 мкс, F — SHA-256 от адресов, портов и ключа вкладки. Подтверждения — ISN + 1 по модулю 2³². Кнопка «номер на краю круга» ставит 4294967295, и ACK честно становится 0.
- **Рисунок 6 из RFC с твоими числами** плюс строка данных: номера считают байты, поэтому «теперь собери группу» — 20 знаков, 38 байт.
- **Покер = угадать номер.** Деталь гравюры Валлоттона — руки и стол без лиц — к истории про предсказуемые ISN (Моррис, 1985).
- **Манифестация = SYN-флуд.** Толпа Валлоттона к атаке 1996 года; кнопка включает SYN cookies Бернштейна, страница раскладывает номер сервера на 5 + 3 + 24 бита и проверяет третий аккорд.
- **Проверь сам** — настоящий снимок tcpdump с этой машины: `[S]`, `[S.]`, `[.]`.

## Факты

Всё про TCP сверено по RFC 9293, 6528, 4987, 9768, 5737, 6335, странице SYN cookies Бернштейна и man-странице tcpdump; снимок tcpdump снят на этой машине 30.10.2026. Модель на JS проверена в node: числа рисунка 6 из RFC (100 → 101, 300 → 301), перенос через 2³², 2000 круговых проверок SYN cookie, отказ поддельному и устаревшему cookie. SHA-256 — 304 совпадения из 304 с эталоном. В браузере (Playwright, 1440 и 390 px) арифметика сошлась во всех режимах, ошибок консоли нет, горизонтальной прокрутки нет.

Рисунок Sideburns сверен только по вторичным источникам: номер и год сходятся у Wikipedia, punk77.co.uk и afka.net, слова — по репродукции в `refs/works/`. Оригинал журнала и статью The Independent (2000) открыть не удалось.

Источники по пунктам — в `SOURCES.md`.
