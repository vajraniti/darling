# ксерокс — панк-ксерокс и copy art

Техника, на которой стоит половина борда: печать, которую убили нарочно. Корни — панк-зины конца 70-х.

## Рефы

- `refs/ref1.jpg` — две головы, построенные кругами и крестами по методу Лумиса. Волосы — россыпь зерна, строительные линии оставлены как часть работы.
- `refs/ref5.jpg` — лилия сухой кистью через жёсткий порог. Белая лилия — главный траурный цветок Запада, символ очищенной души.

## Родословная

- **1977 · Jamie Reid** — God Save the Queen: буквы-вырезки поверх портрета королевы.
- **1977 · Linder Sterling** — Buzzcocks «Orgasm Addict»: фотомонтаж в духе дада.
- **1977 · Slash №1** — панк-зин из Лос-Анджелеса, из него выросла обложка Whole Lotta Red.
- **1979–85 · Raymond Pettibon** — флаеры Black Flag и SST, тушь и ксерокс. Самый чистый предок.
- **до ~1987 · 23 Envelope** — обложки 4AD: размытая фотография, цветные ксерокопии. Ближе всех к лилии.
- **сейчас · Alexis Cros** (Лион) — ксерокс, аэрограф, Letraset, растёкшиеся чернила.
- **сейчас · Gianni Clifford** (Дублин) — год еженедельных ч/б клубных постеров для Hidden Agenda.
- **Copy art** — ксерокс как инструмент художника, 60–80-е (по памяти).

## Как делаются фактуры

- **Ксерокс руками** — двигать лист, пока сканер его читает, и копировать копию.
- **Photoshop** — шум, размытие 0.5–1 px, потом Threshold. Фильтры вешать на смарт-объект.
- **Ризограф** — один барабан на краску, случайный растр, цвета съезжают сами.
- **Спрей-шрифт** — размыть, отрезать порогом, россыпь шума по краю.
- **Дизеринг** — Bayer, Floyd–Steinberg, Atkinson (по памяти).
- **Сухая кисть + порог** — мазок, скан, жёсткий ч/б.
