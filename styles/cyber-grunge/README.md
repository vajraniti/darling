# кибер-гранж — данные как орнамент

Штрихкоды, коды, адреса и гигантский шрифт за краем кадра.

## Рефы

- `refs/ref4.jpg` — «eclipse»: гигантский обрезанный кондансд, штрихкод, полутон, белый дым. `#08SCUR3` — obscure в leet-записи, внизу размытый адрес сайта.

## Родословная

- **1979 · Peter Saville** — Unknown Pleasures: график пульсара CP 1919 как обложка. Предок данных-как-образа.
- **1994 · Tomato** — Underworld «dubnobasswithmyheadman»: разобранная типографика.
- **90-е · The Designers Republic** — Warp и wipEout: кибер-системная графика.
- **сейчас · Bollo / Tobias Bolliger** (Берн) — шрифт-штрихкод, постер Brutalismus 3000. Ближе всех к рефу 4.
- **Witch house** (конец 2000-х) — Unicode-символы, кресты, треугольники как орнамент.
