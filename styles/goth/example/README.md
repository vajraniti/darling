# Пример: BLAKE3 в готике

Задание Гэгэ: «сделай сайт про хеш-функцию, например BLAKE3, в стиле готики — всунь готику туда, где её не было».

Живая версия: https://claude.ai/artifact/Fw7WrYRjVW8AxtDibRGoon. Файл `index.html` открывается локально без сборки.

## Ход

Готика изначально — архитектура, поэтому метафора не наклеена сверху, а взята из устройства функции:

- **Дерево Меркла = нервюрный свод.** Куски по 1024 байта сходятся к корню, как нервюры к замковому камню. Дерево на странице нарисовано стрельчатыми арками и считается по-настоящему для выбранного размера.
- **Семь раундов сжатия = семь печатей.** Страница показывает реальное состояние 4×4 до первого раунда и после каждого из семи, рядом гравюра Дюрера «Снятие пятой и шестой печатей».
- **Хеш = эпитафия.** 64 шестнадцатеричных знака набраны антиквой по центру, как надпись на камне.
- **Эпиграф** — Блейк, «On Virgil»: «Grecian is Mathematic Form / Gothic is Living Form». BLAKE3 ему тёзка.

## Решения и откуда они

| Решение | Откуда |
|---|---|
| светлый «каменный» фон `#e5e3de`, а не чёрный | Closer (Saville), Chrome Hearts, Ann Demeulemeester — готика без чёрного |
| фото в рамке на поле, подпись мелким курсивом | Closer, In the Flat Field |
| одна гарнитура — EB Garamond, моно только в блоках кода | Sacred Bones (EB Garamond); правило «одна-две гарнитуры» |
| знак «·BLAKE3·» мелким капсом с точками | «·CLOSER·» |
| меню из четырёх слов: свод, печати, лавина, код | структура из предмета |
| картинки — фото 1858 года, гравюры 1498 и ~1615 | только настоящий материал, без генерации |
| никакого шума, зерна, глитча, моно-плашек, карточек | `rules/anti-synthetic.md` |

## Факты

Все утверждения о BLAKE3 взяты из README и эталонной реализации официального репозитория BLAKE3-team/BLAKE3. Порт на JS (`blake3.js`) проверен на официальных тест-векторах: 35 длин входа × 3 режима = 105 совпадений из 105.
