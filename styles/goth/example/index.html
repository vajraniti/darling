·BLAKE3·
сводпечатилавинакод

Криптографическая хеш-функция. Внутри у неё дерево: куски по 1024 байта сходятся к одному корню, как нервюры к замковому камню.

Grecian is Mathematic Form
Gothic is Living Form

Уильям Блейк, «On Virgil». Греческое — форма математическая, готическое — форма живая. BLAKE3 — его тёзка, и в ней есть и то и другое.

Свод

BLAKE3 режет вход на куски по 1024 байта. Каждый кусок сжимается сам по себе, поэтому их можно считать одновременно — на всех ядрах и всех полосах SIMD.

Пары кусков сходятся в узлы, пары узлов — в узлы выше, пока не останется один. Это дерево Меркла. Левые поддеревья в нём всегда полные, а узлов на один меньше, чем кусков.

В готическом своде нервюры так же сходятся в одну точку — к замковому камню, который их запирает.

Семь печатей

Каждый блок по 64 байта проходит функцию сжатия. Её состояние — 16 слов по 32 бита, матрица 4×4. Сжатие длится семь раундов.

Раунд — восемь вызовов функции G: четыре по столбцам, четыре по диагоналям. Между раундами слова сообщения переставляются. После седьмого раунда половины матрицы складываются через XOR.

Ниже последнее сжатие для твоей надписи — то, что даёт сам хеш: состояние до первого раунда и после каждого из семи.

Лавина

Возьми свою надпись и поменяй в ней один бит — последний бит последнего байта. Из 256 бит хеша поменяется примерно половина, и заранее не скажешь, какие.

Код

Из командной строки — утилита b3sum, из Rust — крейт blake3. Обе от авторов функции.

Для паролей BLAKE3 не годится: она нарочно быстрая. Для паролей авторы советуют Argon2.

cargo install b3sum
b3sum /tmp/bigfile
let hash = blake3::hash(b"foobarbaz");
println!("{}", hash);
let key = [42u8; 32];
let mac = blake3::keyed_hash(&key, b"example input");

Функция

BLAKE3 спроектировали Jack O'Connor, Samuel Neves, Jean-Philippe Aumasson и Zooko. Разработку спонсировала Electric Coin Company.

Основана на BLAKE2 и древовидном режиме Bao. Выход по умолчанию — 256 бит. Лицензия — CC0 или Apache 2.0.
